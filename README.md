# Recipe Bot

A  Retrieval-Augmented Generation(RAG) system that functions as a cooking assistant answering recipie and coooking domain queries. This project demonstrates a full pipeline of domain-specific knowledge, processing it for efficient retrieval, and leveraging a Large Language Model(LLM) to generate accurate context-aware responses.
